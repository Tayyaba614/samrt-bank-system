# samrt-bank-systemSmartBank System
SmartBank System is a multi-page banking website developed using HTML only.
This project demonstrates basic web development concepts including navigation, tables, forms, lists, and page linkingFeatures
Multi-page website
Navigation menu on all pages
Banking account information
Loan services details
E-Banking login page
Transaction history table (with rowspan and colspan)
Contact form
Online images and icons used
Clean layout using tables
